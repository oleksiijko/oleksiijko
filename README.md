## <img src="https://api.iconify.design/lucide/sparkles.svg?color=%238b949e&height=22" height="21">&nbsp; Featured project &nbsp;·&nbsp; PMB

<div align="center">
<a href="https://github.com/oleksiijko/pmb">
  <img src="https://raw.githubusercontent.com/oleksiijko/pmb/main/docs/assets/dashboard-map.png" width="720" alt="PMB dashboard">
</a>
</div>

> **Local-first persistent memory for AI coding agents.** PMB gives Claude Code, Cursor and
> Codex a real memory - decisions, lessons, facts and project structure - that survives
> every restart, model upgrade and agent switch. SQLite is the source of truth. No cloud, no
> API keys, no LLM call on the read path.
