## 🚀 Featured — PMB · Persistent Memory Brain

<div align="center">
<a href="https://github.com/oleksiijko/pmb">
  <img src="https://raw.githubusercontent.com/oleksiijko/pmb/main/docs/assets/dashboard-map.png" width="760" alt="PMB dashboard — your project's memory as a live entity graph">
</a>
</div>

> **Your AI coding agent forgets everything between sessions.** PMB gives Claude Code,
> Cursor and Codex a real, **local-first** memory — decisions, lessons, facts and project
> structure — that survives every restart, model upgrade and agent switch. SQLite is the
> source of truth. **No cloud, no API keys, no LLM call on the read path.**
